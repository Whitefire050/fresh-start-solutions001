# Fresh Start Solutions

請建立一個一頁式學生企業網站，社會實踐第八組，主要營業項目是 廢生菜的處理研究 這是我們想要放上的和內容，盡量不要修改，我們的內容太少的話，可以多加格子和你覺得需要補充的資料，我們還到時候再改

一個核心問題

如何透過加工或其他方式，減少因外觀不符市場要求及天氣影響，所產生的格外生菜浪費？

what生菜可能因為大小、外觀不符合市場要求，因此被丟棄

who農民、菜商、消費者

When 蔬菜盛產期，或是遇到颱風、連日大雨等天氣劇烈變化之後。

Where 產地的農田、集貨場，以及產地的果菜批發市場。

Why 我們猜是市場過度要求外觀完美，加上產地缺乏加工去化的管道

How 目前可能被丟棄或做堆肥。下一步可以訪問產地農民或市場人員，查詢相關資料。

待確認

如果將格外生菜加工，是否能減少浪費

季節跟天氣是否會影響格外生菜的多寡

三個待確認事項

產地的格外生菜被丟棄的數量與比例？

將格外生菜加工的成本與技術是否可行？

天氣與季節如何具體印響格外生菜的產量？

為什麼要確認這三個問題

了解問題規模確認這是值得研究

驗證加工減少浪費的猜測和天氣影響多寡的猜測

可以向誰用什麼方式去確認

查詢農業統計年報訪困產地農匯或農民

查詢食品加工案例，訪問在地加工廠

查詢氣象與農業災損資料訪問農改廠專家

需求：

使用 HTML5 + CSS3 + JavaScript

不使用 React

不使用 Next.js

不使用 Node.js runtime

不需要資料庫

不需要後端

網站完成後可以直接部署到 Apache

使用 index.html 作為入口
